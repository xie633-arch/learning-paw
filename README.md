# Personal Learning OS

一个面向手机与电脑的个人学习 PWA。V0.3 不再只是“刷卡片”，而是围绕：

**学习新内容 → 主动回忆 → 薄弱专项 → 正式测试 → 再学习**

形成完整学习闭环。

## V0.3 当前模块

- 📱 **手机产品专家**：硬件、参数 → 体验、产品组合、用户、竞争、零售 GTM、上市与经营。
- 🇰🇷 **韩语**：保留 V0.2 的主动表达、听力 / 听写与 TTS；本轮不继续改动，后续单独迭代。
- 🗺️ **商圈与零售**：用户、JTBD、商圈、门店、陈列、Demo、O2O、活动与经营复盘。
- 🌍 **行业与商业**：市场、品牌、产品组合、价格权益、渠道、商业模式、竞争情报与战略判断。

## 新增能力

### 1. 今日学习

每个非韩语领域都有学习路线，系统自动找到第一项未完成内容作为“今日学习”。

### 2. 学习路线

- 手机：8 阶段 Retail GTM 路线；
- 商圈与零售：8 步零售 GTM 路线；
- 行业与商业：8 步行业分析路线。

路线完成状态保存在当前设备，可单独标记完成 / 取消完成。

### 3. 薄弱知识

根据最近学习历史自动统计：

- `✅ 认识` = 0；
- `🟡 模糊` = 1；
- `❌ 不认识` = 2。

按类别生成薄弱度，并可直接发起“专项复习”。

### 4. 正式测试

日常训练仍然只做三档自评；正式测试与日常复习分开。

当前手机、商圈零售、行业商业均提供：

- 10 道客观题；
- 每题 10 分；
- 总分 100；
- 自动判分；
- 测试完成后显示错题与解释；
- 保存最近测试记录。

当前是“基础验收首版”，后续再加入开放题、场景题与系统串联题。

### 5. 官方图识机素材入口

手机模块已经建立官方产品页素材库入口，目前包括：

- HUAWEI Mate 80；
- HUAWEI Pura 80；
- HUAWEI Mate X7。

当前阶段只链接厂商官网，下一阶段把稳定官方图片本地化后，做真正的看图识机卡。

### 6. 数据备份

增加：

- 导出学习数据 JSON；
- 导入学习数据 JSON。

这样在自动跨设备同步完成前，可以先手动备份 / 迁移：

- FSRS 排程；
- 学习历史；
- 学习路线进度；
- 正式测试记录。

## 共同学习逻辑

1. 学新内容；
2. 先主动输出；
3. 再查看参考答案；
4. 日常自评：
   - ✅ 认识
   - 🟡 模糊
   - ❌ 不认识
5. FSRS 安排下一次复习；
6. 薄弱类别进入专项训练；
7. 正式测试独立计分。

日常训练不做 AI 自动判分。

## 数据与隐私

这个仓库是公开部署仓库，因此只放：

- PWA 程序；
- 明确可公开的通用学习题库；
- 公开厂商官网入口。

不会把私有 Obsidian Vault、工作日报、内部资料或私人学习记录直接发布到这里。

当前学习数据仍在浏览器 `localStorage`：

- iPhone 与 Mac 暂不自动同步；
- 可以手动导出 / 导入备份；
- 清除浏览器网站数据前应先导出备份。

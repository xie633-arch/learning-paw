# Personal Learning OS

一个面向手机与电脑的轻量 PWA，用于主动回忆、间隔复习和多领域学习。

## V0.2 当前模块

- 📱 **手机产品专家**：手机硬件基础、参数 → 体验训练；后续加入官方产品图识机。
- 🇰🇷 **韩语**：中 → 韩主动表达、听力 / 听写、系统韩语朗读；AI 连续语音对话与发音纠正是下一阶段核心能力。
- 🗺️ **商圈与零售**：已预留模块，题库后续接入。
- 🌍 **行业与商业**：已预留模块，题库后续接入。

## 共同学习逻辑

1. 先看到题目；
2. 先写下自己的答案；
3. 再查看参考答案；
4. 自评：
   - ✅ 认识
   - 🟡 模糊
   - ❌ 不认识
5. 优先使用 FSRS 安排下一次复习；CDN 不可用时自动退回本地简化排程。

日常训练不做 AI 自动判分，避免把“看到答案觉得会”误当成真正掌握。

## 韩语模块 V0.2

当前已经支持：

- 中 → 韩主动表达；
- 基础句型与生存韩语；

- 与其他领域共用 FSRS、学习记录和到期复习逻辑。

下一阶段重点：

## 数据与隐私

这个仓库是公开部署仓库，因此只放：

- PWA 程序代码；
- 明确可公开的通用学习题库。

不会把私有 Obsidian Vault、工作资料、日报或私人学习记录直接发布到这里。

当前学习进度保存在浏览器 `localStorage` 中，因此：

- Mac 与 iPhone 暂时不会自动同步；
- 清除浏览器网站数据会清除当前设备学习记录；
- 自己填写的答案不会发送给 AI。

## 运行与部署

本地可通过静态服务器运行，例如：

```bash
python3 -m http.server 8765
```

正式版本通过 GitHub Actions 部署到 GitHub Pages。
